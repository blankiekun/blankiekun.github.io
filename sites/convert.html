About

Converts Japanese visual novels you own into games that run on CONscripter, including its WebAssembly build. It reads a game's archives, images, audio and compiled scripts, translates them into an engine-neutral intermediate form, and writes a 0.txt script plus .nsa archives.

It ships no game data and reads only your own installation.

Usage

C:\> conscripter-convert convert-game D:\SAIHATE -o out\imaa --font ipag.ttf --title "最果てのイマ"
Reading archives ........ ok
Decompiling scripts ..... ok
Writing 0.txt, arc.nsa .. ok

C:\> conscripter --root out\imaa

Xuse support

Xuse featureStatus
Archives, images, BGM, sound effects, voicesDecoded
Script text, speaker names, hyperlinksConverted
Control flow: variables, goto, gosub/returnConverted
Transitions with original durationsConverted
Evening and night character tintsPre-rendered
Title, save/load, settings, backlog menusBuilt in-script
MoviesNot yet
Special text displays, ~35 rarer opcodesNot yet

Tested with 最果てのイマ COMPLETE (Xuse).

How it works

  • Each source engine is a separate reader that feeds the same output stage. Xuse is the first; Nitroplus is in progress.
  • Anything it can't convert yet stays in 0.txt as a comment naming the source instruction, and each run prints a ranked list of what was left out.
  • When a game needs something NScripter can't do, the feature is added to CONscripter rather than approximated.
