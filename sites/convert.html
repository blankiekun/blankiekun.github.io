About

Converts Japanese visual novels you own into games that run on CONscripter, including its WebAssembly build, so they play in the browser and in chimimouryou. It reads a game's archives, images, audio and scripts, translates them into an engine-neutral intermediate form, and writes a 0.txt script plus .nsa archives.

It ships no game data and reads only your own installation.

Usage

C:\> conscripter-convert convert-game D:\SAIHATE -o out\imaa --font ipag.ttf --title "最果てのイマ"
Reading archives ........ ok
Decompiling scripts ..... ok
Writing 0.txt, arc.nsa .. ok

C:\> conscripter --root out\imaa

--webp stores images as WebP at about half the size, for the web. Every build writes a version.txt and shows its build date and versions on the settings screen, so a bug report says which build it came from.

How it works

  • Each source engine is a separate reader that feeds the same output stage. Only the output stage knows about NScripter.
  • Anything it can't convert yet stays in 0.txt as a comment naming the source instruction, and each run prints a ranked list of what was left out. How much of each game converts is counted per command call and updated with every change.
  • When a game needs something NScripter can't do, the feature is added to CONscripter rather than approximated: screen filters, shakes, new transitions and text sizes all came from here.
  • Converted games are tested by letting CONscripter play every route by itself and checking its debug trace for errors, missing files and stray sprites.
