::: how much of each game converts, live from the repository :::

Every command call in a game's scripts counts as either fully converted or with a gap: the converter dropped it, approximated it, or left an argument it was given unread. These numbers come from the converter's dry run and are updated in the same pull request as every change to a conversion.

Fetched from the main branch on each load. GitHub's raw file server can be up to 5 minutes behind a merge. The commit is the one the numbers were measured on; "+ its PR" means plus the change that updated them.
