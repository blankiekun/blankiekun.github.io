How much of each game converts

Every command call in a game's scripts is either fully converted or has a gap: the converter dropped it, approximated it, or ignored one of its arguments. Calls left out on purpose, in code the game can't reach such as a debug menu, count as done. The red line shows the share that converts fully. A game reaches the top when nothing is left out.

Where the gaps are

Each game's command kinds, most gaps first, with the reasons the converter gave.

The numbers come from the converter's dry run and change in the same pull request as the code they measure. This page reads them from the main branch each time it loads, so it can lag a merge by up to 5 minutes. "Measured on" names the commit; "+ its PR" means that commit plus the change that updated the numbers.
